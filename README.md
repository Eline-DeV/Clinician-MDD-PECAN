# Clinician-MDD-PECAN
This code is part of submitted academic manuscript titled "Seeing Shades of Blue: Clinicians' Perceived Causal Networks of Major Depressive Disorder". 
It involves the aggregation and analysis of Perceived Causal Networks (PECAN) made by a small group of psychological clinicians. 

Feel free to have a look around to see whether it may be of use to you! If this code helped you perform your own analyses, please consider citing the related zenodo page (where you can also find the related dataset).
